# Literature

A place for project-relevant papers and reading notes. Nothing here is wired into the analysis pipeline — it is for the researcher's reference.

## Suggested layout

```
Literature/
├── papers/        # PDFs of papers you are drawing on
├── notes.md       # Short reading notes, one entry per paper
└── bib.bib        # BibTeX entries you can copy into LaTeX/references.bib
```

None of these are required — add or remove as suits the project. If you maintain `bib.bib` here, keep it in sync with `LaTeX/references.bib` (or just edit `LaTeX/references.bib` directly).
